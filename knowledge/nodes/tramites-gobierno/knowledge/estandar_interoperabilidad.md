# Directriz Técnica de Catalogación

Para garantizar que los trámites puedan ser consultados mediante APIs abiertas y agentes de software, toda ficha de servicio debe contener:

1. **Unicidad del Código:** Código alfanumérico inmutable que preserve la referencia histórica.
2. **Requisitos Normalizados:** Lista de documentos requeridos con enlace a la base jurídica habilitante.
3. **Plazos de Silencio Administrativo:** Determinación de si aplica silencio positivo o negativo ante la falta de respuesta institucional.
